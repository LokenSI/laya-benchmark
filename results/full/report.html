A practical first release

  1. Suggest a category inside the existing workflow and let staff correct it.
  2. Measure handling time, overrides and downstream mistakes on a private holdout.
  3. Validate separate quality targets for Bokmål, Nynorsk and high-cost categories.
  4. Automate only the cases that meet those targets; keep the rest in human review.

Budget for monitoring, maintenance and fallback handling. Keep irreversible actions behind application permissions and appropriate review.

Evaluation protocol

  • Pinned model and dataset revisions; local Python virtual environment; no hosted inference or LLM judge.
  • Official train/validation/test splits. Exact normalized text duplicates removed with test priority. NoReC review groups checked for split leakage.
  • MASSIVE English and Bokmål use the same example IDs and all 18 service categories. This is not a benchmark of all 60 intents.
  • Temperature fitted on one half of validation source groups; policy selected on the other half. Test outcomes do not tune prompts, temperatures or thresholds.
  • 95% accuracy intervals use 2,000 source-group bootstrap resamples. Multiple NoReC sentences from one review remain grouped.
  • All public test errors remain in the results. Failed runs are explicitly marked incomplete.
Public test data may overlap the models' training history. Newly labelled private examples are required for a contamination-resistant production decision.
