Accuracy uses the full scored group under the original split rules. “Answered” includes correct and incorrect answers; its shortfall includes failures, native rejections and abstentions. Timing uses separate fixed samples, batch size one, three serial passes and excluded warm-ups. Medians cover answered calls; blocks with fewer than 90% answered calls are withheld. Counts and native truncation remain visible.

VRAM is the sampled whole-device peak above idle on an RTX 5070 Ti 16 GB, not the model file size or isolated process memory. Desktop activity can affect small differences. Jev response times include network transport; its server VRAM is unknown. Missing measurements are never estimated. CLM timing reuses precomputed candidate embeddings for the fixed workload.

What this means for a business pilot

Start with the actual workflow

Routing requests, tagging engineering documents and selecting developer tools favour different models. Use the matched task results to shortlist candidates, then validate on your own examples and costs of mistakes.

Include the simpler baseline

A supervised TF-IDF + linear SVM reached @@BASELINE@@ on Norwegian routing using labelled training data. The decision models here had no task-specific fitting. If labels are available, include a trained classifier in the pilot.

Industrial routing and document examples are small authored diagnostics, not expert-validated industry benchmarks. These tests do not measure staff-time savings, production safety or return on investment.
